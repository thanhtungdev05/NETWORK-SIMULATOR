CÁC BƯỚC THIẾT LẬP MÔ HÌNH MẠNG LIÊN KẾT

🌐 GIAI ĐOẠN 1: CẤU HÌNH THIẾT BỊ 1 — ONT AC1000F (BRIDGE MODE)
  • 1
    Đăng nhập vào ONT: Tên đăng nhập admin / Mật khẩu admin.
  • 2
    Vào menu Network → WAN:
    • Connection Type: Chọn Bridge Mode (giá trị 3).
    • 802.1q: Chọn Tag (Yes).
    • VLAN ID: Nhập 2502 (VLAN Internet FPT).
    • Bấm Save & Apply để lưu.
  • 3
    Vào menu Network → LAN:
    • Tại mục DHCP Server: Chọn Disable (Tắt cấp DHCP trên modem quang).
    • Bấm Save để hoàn tất biến ONT thành cầu nối quang trong suốt.
🔀 GIAI ĐOẠN 2: CẤU HÌNH THIẾT BỊ 2 — ROUTER DRAYTEK VIGOR 2927
  • 4
    Chuyển sang Tab Thiết bị 2: Router Vigor 2927. Đăng nhập với tài khoản admin / admin.
  • 5
    Vào menu WAN → Internet Access (WAN 1):
    • Access Mode: Chọn PPPoE.
    • Bấm Details Page: Nhập Username sgfdl-210208-218 / Password fpt12345.
    • Bấm OK / Apply để lưu cấu hình quay số PPPoE qua kênh quang.
  • 6
    Vào menu LAN → General Setup (LAN 1):
    • Đổi địa chỉ IP sang 192.168.10.1 (để tránh xung đột mạng với dải 192.168.1.1 của ONT).
    • Kích hoạt DHCP Server cấp phát dải 192.168.10.10 - 192.168.10.200 cho các máy trạm.
    • Bấm OK để lưu.
💻 GIAI ĐOẠN 3: KIỂM TRA THÔNG MẠNG & NỘP BÀI
  • 7
    Chuyển sang Tab Virtual Client (CLI). Chạy lệnh ping 8.8.8.8 hoặc tracert 8.8.8.8.
  • 8
    Khi kết quả báo thông suốt (0% packet loss), bấm nút 📝 Nộp bài & Chấm điểm để ghi nhận kết quả hoàn thành.
