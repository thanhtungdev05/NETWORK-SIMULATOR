Note:
  1. WAN1 and WAN2 cannot work simultaneously, so when one of the interfaces is enabled, the other will be disabled. WAN3 can only serve as the backup WAN for WAN1 or WAN2, depending on which is active.
  2. The line speed setting of WAN interface is available only when According to Line Speed is selected as the Load Balance Mode.
  3. For WAN1 (Combo WAN), SFP port has higher priority than Ethernet port. If SFP transceiver is plugged into SFP WAN port, Ethernet WAN port is disabled even if a cable is plugged in.
  4. In DSL auto mode, the router will reboot automatically while switching between VDSL2 and ADSL lines.
  5. Customer and service tag are used for different network environments. Customer tag is required for most ISPs while Service tag is required when ISP needs QinQ packets.
